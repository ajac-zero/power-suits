Install

Three files and a crafting table. The server and every client both need the mod.

NeoForge

Install NeoForge for Minecraft 26.3.

neoforged.net

GeckoLib 5

Download GeckoLib 5 for NeoForge 26.3 and put it in your mods folder, with the Power Suits jar next to it.

GeckoLib on Modrinth
Download {{version}}

In the game

The suit is in the creative tab Tools & Utilities. In survival, craft a torso, two arms and two legs and assemble them like a body at a crafting table, then craft a helmet and an engine for it. Controls, recipes and every number are in the guide.

Verify your download

Mods from sites you don't know have spread malware before. You don't have to take our word for this one.

Built in public

GitHub builds every release from the public source, with a workflow anyone can read. The release links to its build log.

Signed

GitHub signs a record of each build: this file, from this repository, at this commit. With the GitHub CLI, check your jar:

gh attestation verify {{jar}} -R ajac-zero/power-suits

Checksum

Each release lists the jar's SHA-256. Compare it with yours:

shasum -a 256 {{jar}}

On Windows: certutil -hashfile {{jar}} SHA256

Rebuild it yourself

The same source gives the same file, byte for byte. Check out the release's tag and build it with Temurin {{java}} and the reproducible.gradle script: ./gradlew build --init-script reproducible.gradle. The checksum should match.

The mod adds the suit, its parts and tools to the game. It makes no network connections of its own, runs no other programs and loads no code from anywhere else. Its only dependencies are NeoForge and GeckoLib.
