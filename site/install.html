Install

  1. Install NeoForge for Minecraft 26.3.
  2. Download GeckoLib 5 for NeoForge 26.3 and put it in your mods folder.
  3. Download Power Suits ({{version}}) and put the jar next to it.

Every version is on the releases page. The server and every client both need the mod.

In the game

The suit is in the creative tab Tools & Utilities. In survival, craft a torso, two arms and two legs and assemble them like a body at a crafting table, then craft a helmet and an engine for it. Controls, recipes and every number are in the guide.

Verify your download

Be careful with mods from websites you don't know: malware has spread through Minecraft mods before. You don't have to take our word for this one.

Built in public

GitHub builds every release from the public source code, with a workflow anyone can read. The release links to its build log.

Signed

GitHub signs a record of each build: this file, from this repository, at this commit. With the GitHub CLI, check the jar you downloaded:

gh attestation verify {{jar}} -R ajac-zero/power-suits

Checksum

Each release lists the jar's SHA-256. Compare it with yours: shasum -a 256 {{jar}} (macOS, Linux) or certutil -hashfile {{jar}} SHA256 (Windows).

Rebuild it yourself

The same source gives the same file, byte for byte. Check out the release's tag and build it with Temurin {{java}} and the reproducible.gradle script: ./gradlew build --init-script reproducible.gradle. The checksum should match.

The mod adds the suit, its parts and tools to the game. It makes no network connections of its own, runs no other programs and loads no code from anywhere else. Its only dependencies are NeoForge and GeckoLib.
